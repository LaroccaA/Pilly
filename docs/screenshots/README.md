# Screenshots

These captures were produced from the web build at a 390 × 844 viewport with
generic demo data. The same React Native screens are used on Android and iOS.

To refresh them:

1. run `npm run web` or `npx expo export --platform web`;
2. seed the local storage with the demo catalog and packages;
3. capture the inventory, manage-stock modal, add-box modal, and pill-count
   screens at the same viewport.

Replace the PNG files in this folder and keep the file names referenced by the
root `README.md`.
